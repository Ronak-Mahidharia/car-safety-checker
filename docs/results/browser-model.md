# Browser model

Generated by `scripts/build_browser_model.py`. Don't edit by hand.

The live demo runs a small version of the keyword model in the browser: 20,000 terms instead of 272,088, with 8-bit weights. The problem description is analyzed on the visitor's device and isn't sent anywhere.

## Checks

- The plain-Python steps with full-precision weights match scikit-learn's probabilities on 2,000 dev complaints (largest difference 1.9e-15).
- 8-bit weights: dev micro F1 0.7383, against 0.7381 with full-precision weights; the same answer for 98.75% of 62,366 dev complaints.
- Threshold 0.35, chosen on the dev split.
